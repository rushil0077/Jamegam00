- Crumb Rush is a survival game where players control a little guy collecting falling crumbs while avoiding obstacles.
- Players move left and right using the arrow keys or A/D keys.
- Collecting crumbs increases the player's score, while getting hit by falling boots causes them to lose a life.
- Players start with three lives, and the game ends when all three are lost.
- Players can try to beat their saved high score.
